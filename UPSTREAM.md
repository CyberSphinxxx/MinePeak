# Upstream attribution

MinePeak adapts PeakCraft by aeironnsarmiento, itself based on SkyCraft by chasmlol.

**MinePeak is the current project name.** PeakCraft and SkyCraft refer to the credited upstream projects. Their internal namespaces, plugin/mod identifiers and save/config filenames are retained for compatibility; the PEAK plugin display name, Minecraft bridge display name, launcher and local bundle use MinePeak.

- PeakCraft: https://github.com/aeironnsarmiento/PeakCraft
- Pinned revision: d07030ee527ee2a2facc989f5acae8a317968c02 (2026-10-02)
- SkyCraft: https://github.com/chasmlol/SkyCraft
- Upstream MIT licences and third-party notices are retained under vendor/PeakCraft.

The project ships mod code only. Game assemblies, Minecraft assets, account information,
world saves and downloaded development tools are excluded from source control.
